# The Parisi formula

By Michel Talagrand. The SK proof in Lean is from Qiang Wu’s ParisiFormula project. The passage links, comparisons, notes and supplementary Lean checks are contributed by this project with AI assistance.

**[Read it](https://wcook04.github.io/library/talagrand-parisi/)** · [The library](https://wcook04.github.io/library/) · [Source and tools](https://github.com/wcook04/lean-exposition)

The upstream proof covers the exact-covariance SK model. The three files under Supplements contain separately checked reader contributions.

The Lean shown here has 303 modules and 2,672 declarations.
